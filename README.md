# 📱 Bể Màn Hình Troll (Broken Screen Prank)

Ứng dụng troll vỡ màn hình chân thực dành cho Android được xây dựng bằng **Kotlin** & **Jetpack Compose (Material 3)**.

---

## ✨ Tính Năng Nổi Bật

- 💥 **Vết nứt kính chân thực tại đúng điểm chạm ngón tay:** Tính toán và vẽ tia nứt mạng nhện 3 lớp (bóng khúc xạ 3D, viền kính pha lê, tim nứt trắng bóng) trực tiếp từ toạ độ ngón tay chạm vào.
- 🖤 **Đốm mực đen AMOLED loang:** Chạm càng nhiều lần, màn hình càng hư hại nặng và xuất hiện đốm đen chảy mực hữu cơ lan dần ra xung quanh.
- 🌈 **Sọc màn hình nhiều màu (RGB dead pixel lines):** Mô phỏng hỏng panel hiển thị với các dải sọc neon xanh, hồng, trắng, vàng rạch ngang dọc màn hình kèm hiệu ứng chớp nháy.
- 🔊 **Âm thanh vỡ kính sống động & Rung giật mình:** Bộ tổng hợp âm thanh PCM chất lượng cao (Vỡ cực mạnh, Nứt giòn tan, Kính ô tô, Chập điện) kèm rung haptic cực gắt khiến bạn bè giật mình hoảng sợ.
- 🪟 **Lớp phủ toàn hệ thống (System Overlay):** Cho phép màn hình bể xuất hiện đè lên **bất kỳ ứng dụng nào** (Facebook, TikTok, YouTube, Game...).
- ⏱️ **Hẹn giờ kích hoạt (Timer):** Đặt thời gian đếm ngược 5s, 10s, 15s, 30s rồi đưa máy cho bạn bè.
- 🔄 **Thoát trở lại bình thường dễ dàng:** Chỉ cần **nhấn phím Back 2 lần liên tục**, màn hình sẽ lập tức phục hồi như chưa hề có chuyện gì xảy ra!

---

## 🚀 Hướng Dẫn Tải Về & Cài Đặt (APK)

1. Tải file **`app-debug.apk`** từ thư mục `app/build/outputs/apk/debug/` hoặc trong mục **Releases** trên GitHub.
2. Mở file `.apk` trên điện thoại Android và chọn **Cài đặt**.
   *(Nếu hệ thống hiển thị thông báo "Ứng dụng không rõ nguồn gốc", chọn "Vẫn cài đặt / Install anyway")*.
3. Mở ứng dụng, cấp quyền **Hiển thị trên ứng dụng khác** (nếu dùng chế độ lớp phủ), sau đó chọn chế độ troll và tận hưởng!

## 🛠️ Biên Dịch Từ Mã Nguồn (Build from Source)

```bash
# Clone repository
git clone https://github.com/your-username/broken-screen-prank.git
cd broken-screen-prank

# Build APK debug
gradle assembleDebug

# File APK được tạo tại:
# app/build/outputs/apk/debug/app-debug.apk
```
